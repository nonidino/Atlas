# Every dependency, pinned to an exact version. Nothing here is resolved by
# "latest": a demo that installs a different set of packages on every machine is
# a demo whose numbers cannot be compared between machines.
#
# torch is NOT here. It is installed separately by run.sh / run.cmd, because
# which wheel is right depends on the machine: the CPU-only wheel is a tenth of
# the size and is the default, and a CUDA one is installed instead when an
# NVIDIA driver is actually present. See TORCH in the launchers.
#
# There is no `transformers`, no `safetensors`, no `huggingface-hub` and no
# `scOT` here, and that is not an oversight -- it is the difference between this
# bundle and the PoC 1a one. Every expert in this demo is a classical solver,
# and the beat that offers a frozen neural operator hands the compiler its
# DECLARATION rather than its weights, because the declaration is where the
# verdict comes from. So nothing is downloaded at install time or at run time
# past what pip fetches, and the whole bundle is about five megabytes.
