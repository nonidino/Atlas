# Every package the workbench imports, pinned to the exact version it was
# built and tested with. Nothing here is "latest": a demo that installs a
# different set of packages on every machine is a demo whose numbers cannot be
# compared between machines.
#
# What THESE pull in is pinned too, in constraints.txt, which the launchers
# pass with -c. A constraint installs nothing that no requirement asks for, so
# one file serves every platform.
#
# Each of these publishes wheels for CPython 3.10, 3.11 and 3.12 on Windows,
# on macOS (Apple silicon and Intel) and on Linux (x86-64), which is why the
# launchers accept exactly those three Pythons: numpy 1.26.4, scipy 1.13.1 and
# pandas 2.2.2 publish none for 3.13.
#
# Not here, and installed by the launchers as OPTIONAL steps (if either fails,
# everything else runs):
#   torch 2.7.1   the learned case, CPU-only; no Intel-macOS wheel exists
#   gmsh 4.15.0   File > Import geometry from Gmsh; GPL, so installed from
#                 PyPI on this machine and never shipped in this folder

numpy==1.26.4

pydantic==2.12.5

# The page: Panel serves it through Bokeh's Tornado server, which carries the
