Install

Try the demo

One command. Your laptop.

The workbench is the demo: choose a kind of physics, draw the domain, cut it into pieces, and run the pieces against the undivided domain. It shows whether they agree, which was faster on your machine, and what the compiler says about joining the pieces.

Before launch. The demo's repository becomes public on the day this site does. Until then the commands below will not find it.

Install and run

Open a terminal, paste the three lines for your system, and press Enter. The script builds a private Python environment inside the folder it creates, installs every package at a pinned version, runs a self-test once, and opens the workbench in your browser. Later runs go straight to the page.

In PowerShell, which Windows opens by default.

git clone --branch atlas-workbench --single-branch https://github.com/nonidino/atlas-workbench.git atlas-workbench
cd atlas-workbench
.\run.cmd

The .\ matters: PowerShell does not run programs from the current folder without it.

Not verified on a Mac yet. No Mac was available to test it. The script is written for the shell macOS ships, and every pinned package publishes macOS wheels, so it is expected to work. If it does not, tell us what it printed.

git clone --branch atlas-workbench --single-branch https://github.com/nonidino/atlas-workbench.git atlas-workbench
cd atlas-workbench
./run.sh

The learned example needs Apple silicon: its library publishes no wheel for Intel Macs. Everything else runs on both.

git clone --branch atlas-workbench --single-branch https://github.com/nonidino/atlas-workbench.git atlas-workbench
cd atlas-workbench
./run.sh

On Debian and Ubuntu the system Python ships without its venv module; the script says so and names the package to install.

No git? Download the branch as a zip from the repository page, unpack it, and run the same script inside it.

What it needs

Python
Python 3.10, 3.11 or 3.12. The script checks the version before installing anything.
A graphics card
Not needed. Everything runs on the processor.
Disk
About 2.0 GB with every optional part, most of it the library the learned example uses. You can skip that part.
Network
Only while installing. The page itself needs none.
How long
On the laptop the results were measured on, a fresh copy's install and self-test took 229 s (pip's download cache was already warm, so a first download takes longer).

What you will see

A real screenshot, taken on a small cloud machine while this site was built. The speed it shows is that machine's; on yours it will differ, and the page says which was faster on your machine.

The workbench opens in your browser. Its header picks the kind of simulation; Fast example opens the case built to show that kind's best honest speed, and says what limits it when there is none. Compile asks the compiler about every seam. Run races the pieces against the whole domain and shows whether they agree, and which was faster on your machine.

Options

--checkRun the self-test alone.
--no-openServe the page without opening a browser.
--reinstallDelete the private environment and build it again.
--no-torchSkip the library the learned example uses, the largest download.
--no-gmshSkip Gmsh, used only to import geometry from Gmsh.

Uninstall

Delete the folder. Nothing is installed outside it.

Licences

Gmsh is licensed under the GPL, so it is never shipped with the demo: the script installs it from the Python Package Index on your machine, as an optional part. The learned example's network was trained by this project from its own simulations.
