The evidence

Every number, and where it comes from.

No number on this site is typed by hand. Atlas's own numbers are read from run records by a script; published results are quoted from their sources. A test fails if the site shows a number that is in neither list, or if a number differs from its record.

Records are published with the computer's name, process ids, local folder paths and log excerpts removed; every other value is the record's own, and each copy names the original file and its checksum.
